# إلى لولي ♡

موقع رومانسي ثابت جاهز للنشر على Vercel.

## التشغيل محليًا
افتح `index.html` في المتصفح، أو شغّل خادمًا محليًا من مجلد المشروع:
`python -m http.server 8000`

## النشر على Vercel
1. فك ضغط الملف.
2. ارفع محتويات مجلد `loly-surprise` إلى مستودع GitHub.
3. من Vercel اختر Add New Project ثم Import للمستودع.
4. اترك Framework Preset على Other، ولا تحتاج Build Command أو Output Directory.
5. اضغط Deploy.

## التخصيص
- كلمة السر في `script.js` داخل `PASSWORD`.
- التاريخ والوقت في `script.js` داخل `new Date(2026, 2, 23, 3, 0, 0)`.
- الصور والأغنية موجودة في مجلد `assets`.

ملاحظة: كلمة السر هنا بوابة لطيفة داخل الواجهة وليست حماية أمنية حقيقية؛ ملفات الموقع الثابتة يمكن الوصول إليها تقنيًا من المتصفح.
